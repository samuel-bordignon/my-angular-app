# Angular Desafios – Focado em Angular

Este projeto é diferente do anterior.

Aqui os problemas são focados em **recursos do Angular**, não em arquitetura conceitual.

## O que você vai praticar

- Interpolação
- Property binding
- Event binding
- Two-way binding (ngModel)
- @Input
- @Output
- Comunicação pai/filho
- Atualização de listas
- Estado local
- Classe e estilo dinâmico
- Renderização condicional
- Pipes básicos
- Forms simples
- Erros comuns de template

---

## Como usar

```bash
npm install
npm start
```
